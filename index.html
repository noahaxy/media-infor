Konsep Interaksi Manusia dan Komputer (IMK)

Sistem komputasi terdiri atas perangkat keras (hardware) dan perangkat lunak (software) yang saling berinteraksi. Antarmuka (interface) menjadi jembatan penghubung antara pengguna dengan sistem komputer.

Manusia (User) Antarmuka (Interface) Software (Aplikasi & OS) Hardware (CPU/RAM) Output (Layar/Suara)

1. GUI (Graphical User Interface)

Interaksi berbasis visual menggunakan ikon, menu, tombol, textbox, radio button, dan jendela visual.

2. CLI (Command Line Interface)

Interaksi berbasis perintah teks secara langsung melalui terminal atau Command Prompt tanpa grafik.

3. Audio / Voice Interface

Interaksi menggunakan perintah suara pengguna (seperti Google Assistant atau Siri).

4. Gambar / Video

Interaksi menggunakan deteksi kamera, face recognition, gesture tracking, dan pemrosesan visual.

5. Piranti Masukan (Input Hardware)

Keyboard fisik/virtual, mouse, touchpad, touchscreen, joystick, dan sensor fisik yang merespons tindakan manusia menjadi sinyal digital.

Klasifikasi Software & Peran Sistem Operasi

Software dikelompokkan menjadi **System Software** (Sistem Operasi seperti Windows, Linux, macOS, Android) dan **Application Software** (seperti Chrome, CapCut, Ms Word, WhatsApp).

System Software (OS)

Menjadi pengelola utama sumber daya komputer (hardware & memory), menjembatani aplikasi dengan perangkat keras.

Application Software

Program khusus yang dirancang untuk menyelesaikan tugas spesifik pengguna (mengedit, mengetik, browsing, dll).

10 Fungsi Utama Sistem Operasi (OS)

1. Antarmuka

Sediakan GUI/CLI untuk interaksi user.

2. Kontrol I/O

Kelola masukan & keluaran data.

3. Periferal

Atur printer, mouse, keyboard.

4. Eksekusi App

Jalankan dan tutup aplikasi.

5. Kelola File

Atur struktur folder & berkas.

6. Kelola CPU

Scheduler pembagian giliran CPU.

7. Kelola Memori

Alokasikan ruang RAM aplikasi.

8. Multitasking

Atur interupsi & jadwal proses.

9. Keamanan

Proteksi sandi & hak akses.

10. Jaringan

Atur koneksi internet & WiFi.

Panduan Guru: Menghubungkan ke Google Sheets (3 Langkah Mudah)

  1. Buat Spreadsheet Baru di Google Drive Anda. Sertakan header baris 1: Timestamp, Nama, Kelas, Kelompok, Nilai Pretest, Nilai Posttest, Jawaban LKPD, Refleksi.
  2. Klik menu Ekstensi $\rightarrow$ Apps Script, hapus kode lama dan **Paste** kode berikut:
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    
    sheet.appendRow([
      new Date(),
      data.nama || "",
      data.kelas || "",
      data.kelompok || "",
      data.pretestScore || 0,
      data.posttestScore || 0,
      JSON.stringify(data.lkpd || {}),
      JSON.stringify(data.refleksi || {})
    ]);
    
    return ContentService.createTextOutput(JSON.stringify({result: "success"}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService.createTextOutput(JSON.stringify({result: "error", error: err.toString()}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
